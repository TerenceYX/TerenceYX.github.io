Privacy policy

TYX Portfolio Automation · last updated 28 October 2026

Who uses it

This is a private tool used only by its owner. It is not available to anyone else.

What it accesses

With the owner's consent, it uses the Google Drive and Google Sheets APIs to read and update files in the owner's own Google Drive. It does not request access to Gmail, Calendar, Contacts or any other Google service.

How data is handled

  • Data is used only to carry out the owner's own tasks on his own files.
  • Access tokens are stored only on the owner's computer, protected by disk encryption and file permissions.
  • No data is sold, shared with third parties, used for advertising or used to train AI models.

Revoking access

The owner can withdraw access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
